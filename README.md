# Kakao Theme Maker

## 설치 및 실행

### 필수 조건
1. Node.js: 최신 LTS 버전 권장

### 명령어
```bash
# 1. 저장소 클론 (Main 브랜치)
git clone https://github.com/kakao-theme-maker/Web-frontend

# (develop 브랜치 타겟)
git clone -b develop https://github.com/kakao-theme-maker/Web-frontend

# 2. 의존성 설치
npm install

# 3. 로컬 개발 서버 실행
npm run dev
```
